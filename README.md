# 阅 · HTML 阅读批注器

一个供电脑浏览器使用的本地 HTML 阅读小工具。打开或拖入一篇 HTML，选中文字高亮并写下想法，读完后导出 Markdown 或复习图片。

![功能示意图](assets/preview.png)

## 开始使用

1. 点击 GitHub 仓库右上角 **Code → Download ZIP**，解压后找到 [`index.html`](index.html)。
2. 在电脑上用 Chrome 或 Edge 打开 `index.html`。
3. 点击右侧「打开」，或把 `.html`、`.htm`、`.xhtml` 文件拖入阅读区。
4. 选中文字后点击「高亮并批注」，在右侧写下想法。
5. 从右侧「导出」下载 Markdown 或复习长图。右上角按钮可进入全屏，按 Esc 退出。

不需要安装软件或运行服务器。工具不会改写导入的原 HTML 文件。

## 功能

- 电脑端全屏阅读，左右分栏显示文章与批注
- 高亮选中的文字，并为每条高亮添加想法
- 在当前浏览器保存阅读历史、划线和阅读位置
- 导出带原文标题、来源网址（原 HTML 提供时）和批注的 Markdown
- 导出单条复习卡或整篇复习长图

## 使用边界

- 这是电脑端工具，目前没有手机适配。
- 阅读历史和批注保存在当前浏览器中。清理浏览器网站数据、换浏览器或换电脑后，记录可能无法找回；请定期导出。
- 每次只导入一篇 HTML；文章里指向其他本地 HTML 的链接需要另行导入。目录跳转暂不包含在这个分享版中。
- 原文标题和网址只会在来源 HTML 中找到相关信息时写入导出结果。导入的 HTML 若引用外部图片或样式，浏览器仍可能请求这些资源。
- 这是自用需求做出的早期版本，欢迎通过 GitHub Issues 反馈可复现的问题。
